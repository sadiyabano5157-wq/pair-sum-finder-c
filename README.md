# pair-sum-finder-c
A simple C program that finds all pairs in an array whose sum is equal to a given target value.

# Pair Sum Finder in C

## 📌 Description
This program finds all pairs of elements in an array whose sum is equal to a target value.

## 🚀 How It Works
- Store numbers in an array.
- Set a target sum value.
- Compare every possible pair.
- Print pairs whose sum matches the target.
- Count total matching pairs.


## 📤 Output

```text
(2 10)
(3 9)
(4 8)
(5 7)
Total pairs = 4
```

- Arrays
- Nested Loops
- Conditional Statements
- Pair Sum Logic
